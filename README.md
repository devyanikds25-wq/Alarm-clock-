Simple Alarm Clock ⏰

Project Description

Simple Alarm Clock is a basic Python application that allows the user to set an alarm for a specific time. The program continuously checks the current system time and triggers an alert when the set alarm time is reached.

Objectives

- To create a simple alarm clock using Python.
- To allow the user to set an alarm time.
- To check the current system time.
- To trigger an alert when the alarm time matches the current time.

Functions

"set_alarm()"

Sets the alarm time entered by the user.

"check_time()"

Checks the current system time and compares it with the set alarm time.

"trigger_alert()"

Triggers the alarm notification when the current time matches the alarm time.

Technologies Used

- Python
- "time" module

Learning Outcomes

- Understanding Python functions
- Working with time in Python
- Using loops and conditional statements
- Taking user input
- Building a simple real-world application
